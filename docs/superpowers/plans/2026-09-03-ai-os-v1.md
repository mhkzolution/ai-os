# AI OS V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a production-ready AI OS NestJS platform (api + worker) that products call with `X-API-Key` and admins manage with JWT, including PRODUCT_ANALYSIS, playground, usage, and cost tracking.

**Architecture:** Modular NestJS monolith, two processes (`src/main.ts` HTTP, `src/worker.ts` BullMQ), PostgreSQL + Redis. Domain modules never import vendor SDKs. Spec: `docs/superpowers/specs/2026-09-03-ai-os-design.md`.

**Tech Stack:** NestJS 11, TypeScript 5, Prisma 7 (`@prisma/adapter-pg` + `pg`), PostgreSQL 16, Redis 7, BullMQ, class-validator, Swagger, Docker Compose, Jest.

## Global Constraints

- API prefix `/api/v1`; Swagger at `/api/docs`.
- Management auth: `Authorization: Bearer <JWT>` only. `JWT_TTL_HOURS=8`. No refresh token (ADR 001).
- Execution auth: `X-API-Key` only. Never accept API keys as Bearer (spec §4.2).
- Admin jobs: `AdminJobsController` at `/api/v1/admin/jobs`. Product jobs: `JobsController` at `/api/v1/jobs` (ADR 002).
- `shared/*` must not import `modules/*`. Modules must not import vendor SDKs.
- Prompts never hardcoded in handlers; seed file only.
- Cost always from execution/playground **snapshot** prices, never live `Model` prices. **M8 lock:** `CostsService` reads `Execution.modelSnapshot` (or playground equivalent) as the source of truth — never the current `Model` table row.
- CI must not call OpenAI/Gemini/Claude/OpenRouter. Use `FakeAIProvider`. **M9 lock:** quality gates only (`lint:check`, `typecheck`, `test:ci`, `build`). No new product features, no vendor SDKs.
- Retention: keep forever (ADR 003). One active prompt version via partial unique index + transaction (ADR 004). **M3 lock:** `PromptsService.activate()` must run inside `prisma.$transaction` (deactivate current active → activate target → commit). Never two floating `update` calls — concurrent admins can collide on `Prompt_key_one_active`.
- IDs: `cuid()`. Passwords: bcrypt cost 12. Client keys hashed (sha256). Provider keys encrypted (`APP_ENCRYPTION_KEY`).
- Worker timeout 60s per attempt. BullMQ `attempts: 3`, exponential backoff, same provider.
- Error JSON: `{ code, category, message, retryable }`. Other-client job → HTTP 404. Playground timeout → 504. HTTP 500 only for API bugs.
- Do not implement roadmap items (fallback, HMAC, webhooks, IP enforcement, Idempotency-Key).

export type PriceSnapshot = {
  inputPricePer1k: number;
  outputPricePer1k: number;

export function calculateCost(
  tokensInput: number,
  tokensOutput: number,
  snapshot: PriceSnapshot,
): number {
  return (
    (tokensInput / 1000) * snapshot.inputPricePer1k +
    (tokensOutput / 1000) * snapshot.outputPricePer1k
  );
}
